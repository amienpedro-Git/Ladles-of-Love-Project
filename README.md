# Ladles-of-Love-Project
A socio-technical web application for Ladles of Love (NPO) designed to streamline Early Childhood Development (ECD) center operations, inventory management, and volunteer tracking. Built with React (TypeScript), Tailwind CSS, and Supabase.
Ladles of Love (LoL) – ECD & NPO Management Platform

A modern, responsive socio-technical web application built for Ladles of Love (NPO). This platform streamlines operations across Early Childhood Development (ECD) centers, managing inventory distribution, volunteer scheduling, and operational reporting.

Developed as part of the INF3003W Systems Development Group Project at the University of Cape Town (UCT).

---

 Tech Stack

- Frontend: React (TypeScript), Vite, Tailwind CSS
- Backend & Database: Supabase (PostgreSQL, Row-Level Security, Authentication)
- State & Data Fetching: React Query / Context API
- Deployment: Vercel / Netlify

---

Key Features

- ECD Center Management: Track participating centers, contact information, and delivery locations.
- Inventory & Distribution Tracking: Monitor stock levels and streamline food distribution workflows.
- Volunteer Portal: Schedule, track, and assign volunteers to active community initiatives.
- Role-Based Access Control (RBAC): Secure authentication and granular permissions implemented via Supabase Row-Level Security (RLS).
- POPIA Compliant: Built with data privacy and protection mechanisms for managing vulnerable entity data.

---

Architecture & Security

- Single Page Application (SPA): Fast, client-side rendering with responsive UI design.
- Data Security: Row-Level Security (RLS) policies enforce restricted access across administrative and operational roles.
- API Integration: Modular backend service calls connecting frontend interfaces to Supabase services.
